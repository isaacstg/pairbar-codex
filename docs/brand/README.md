# Pairbar identity

Pairbar = two accounts paired in the macOS menu bar. The repository is `isaacstg/pairbar-codex`. Its former `pairbar` and `codex-dual-account-switcher` URLs redirect; the description and README retain ChatGPT/Codex account-switcher keywords for discoverability.

- **Tagline:** ChatGPT & Codex profiles, right from your Mac menu bar.
- **Palette:** ink `#0B1220`, mint `#69DCC8`, amber `#F6BC73`, paper `#F4F7FB`.
- **Mark:** a dark rounded square containing paired mint and amber profile shapes, matching the Pairbar app icon.
- **Assets:** `logo.svg` and `banner.svg` are editable, first-party static vectors. `social-preview.png` is a 1280×640 export for GitHub's social preview setting and link cards.

The banner is a simple brand hero with no app interface illustration. Product screenshots in the main README are captured from Pairbar's inert preview and use synthetic data.

All assets use the repository's MIT license. Social-preview upload is a separate repository UI setting; adding the PNG to Git does not automatically configure that setting.
